# PawTime 🐾

A cozy, pastel focus stopwatch with virtual pet companions and a local session journal.

## Run locally
Open `index.html` in a browser.

## Publish
Upload `index.html`, `style.css`, and `app.js` to a GitHub repository. In Netlify, import that repository. No build command is needed; publish directory is `/`.

Session history and today's totals are saved in the browser using localStorage.
